AutoCare

Платформа для автосервиса: клиенты и автомобили, записи на обслуживание, заказ-наряды и склад запчастей.

Приложение написано на ASP.NET Core Blazor Server (.NET 10) и работает на хостинге с поддержкой .NET. Netlify не запускает .NET-серверы, поэтому здесь размещена только эта страница.

  • Запуск локально: dotnet run
  • Демо-вход: admin@autocare.local / AutoCare123!
